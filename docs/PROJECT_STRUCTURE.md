## Conventions

**Imports.** `@/` resolves to `src/`. Server-only modules end in `.server.ts`. No
`server-only` package: TanStack Start does not use the Next.js convention, and ESLint
blocks importing it by mistake.

**Components.** One responsibility per file. `components/ui/` is vendored and may exceed
the line limit. Everything else is capped at 250 lines.

**State.** TanStack Query for anything from the database. `useState` for local UI state.
No global state library, and none is needed until something demands it.

**Styling.** Tailwind utilities referencing semantic tokens, never raw hex values.
Tokens are defined once in `src/styles.css`.

**Text.** No hardcoded user-facing strings in components once i18n lands (Sprint 9).
Arabic is the source language.

**Prices.** Formatted through a single helper: Western digits, comma grouping, `DA`
suffix, locked LTR. Never `Intl` with a locale that produces Arabic-Indic digits.
