OpenStore DZ — Design System

The palette, type scale and components the storefront ships. Ported value-for-value from the Commerce Storefront reference system (system 02), which is a component-CSS system rather than a utility system.

Two values deviate from the reference, both for WCAG AA. The reference primary #d9480f measures 4.29:1 white-on-orange and 4.02:1 orange-on-cream, under the 4.5:1 floor for text below 18.66px, so it fails on every button label. #c2410c is the same hue one step darker and passes both. Muted text was likewise darkened from #78716c to #6b6460. Both are asserted by e2e/accessibility.spec.ts.

Colour

One accent carries the brand: burnt orange. Berry and amber exist for emphasis and for states, not as a second brand colour.

Typography

Display is Fraunces, body is Outfit, both variable, both self-hosted. Cairo is added to every stack because the reference is Latin-only and would otherwise fall back to whatever Arabic face the operating system happens to have.

Arabic density override

Arabic is set at 17px / 1.75 against Latin's 15px / 1.5. Arabic has a smaller x-height at the same nominal size, so the Latin value reads cramped. This is legibility, not decoration.

Direction

Arabic is the primary language and RTL is the default direction, not a mode. Layout properties are logical (padding-inline, margin-inline, inset-inline) so a single set of rules serves both directions. Prices and identifiers stay LTR inside RTL text.

Rules that are not style preferences

  • Light is the default and it is enforced. A dark-mode phone must not turn the shop dark before the buyer chooses; it would misrepresent the seller's photography.
  • Tap targets are at least 32px, and 44px for primary controls. Measured against the built output, not assumed.
  • Contrast passes AA on every page. axe-core runs against the visitor pages in CI, including the contrast rule.
  • Reduced motion is respected. Every animation collapses under prefers-reduced-motion.
  • No horizontal overflow at 320px. A page that can be dragged sideways reads as broken on a phone.

Source of truth: src/styles.css. If this page and that file disagree, the file wins and this page is wrong.
