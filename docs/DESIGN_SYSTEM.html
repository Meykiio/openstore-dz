OpenStore DZ — Design System

The palette, type scale and components the storefront ships. The shop's photography sets the palette: warm paper, ink type, one oxblood accent. Product cards carry no frame so the photograph sits on the page instead of inside a box.

Every value is measured for WCAG AA. Ink on paper is 15.9:1; muted text on paper is 6.1:1; paper on oxblood is 9.7:1. Prices and identifiers use IBM Plex Mono so a figure cannot reflow inside an Arabic sentence. Both themes are asserted by e2e/accessibility.spec.ts.

Colour

One colour carries the brand: oxblood. Ink and paper do the rest. Amber and teal exist for warnings and states, not as second brand colours.

Typography

One Latin family: Geist, at three registers. Heavy and tight for the wordmark and the hero, regular for body, and nothing decorative in between. Outfit sets the interface; IBM Plex Mono sets money. Cairo is added to every stack because a Latin-only stack would otherwise fall back to whatever Arabic face the operating system has.

Arabic density override

Arabic is set at 17px / 1.75 against Latin's 15px / 1.6, and loses Latin letter-spacing on display type. Arabic has a smaller x-height at the same nominal size, so the Latin value reads cramped. This is legibility, not decoration.

Direction

Arabic is the primary language and RTL is the default direction, not a mode. Layout properties are logical (padding-inline, margin-inline, inset-inline) so a single set of rules serves both directions. Prices and identifiers stay LTR inside RTL text.

Rules that are not style preferences

  • Light is the default and it is enforced. A dark-mode phone must not turn the shop dark before the buyer chooses; it would misrepresent the seller's photography.
  • Tap targets are at least 32px, and 44px for primary controls. Measured against the built output, not assumed.
  • Contrast passes AA on every page. axe-core runs against the visitor pages in CI, including the contrast rule.
  • Reduced motion is respected. Every animation collapses under prefers-reduced-motion.
  • No horizontal overflow at 320px. A page that can be dragged sideways reads as broken on a phone.

Source of truth: src/styles.css. If this page and that file disagree, the file wins and this page is wrong.
